# PLAYABLE — A Game Design Atlas

A self-contained static site cataloging influential and unusual video games, including artwork, manuals, estimated playtimes and personal progress tracking.

## GitHub Pages

This site is ready to publish using **Settings → Pages → Deploy from a branch** with **main** and **/(root)**.

No build step is needed. Game artwork is hosted by the Libretro community thumbnail archive, and progress is stored in your browser's local storage.
